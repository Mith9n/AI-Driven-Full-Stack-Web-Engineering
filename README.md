## Overview

This repository tracks progressive, hands-on learning across the modern front-end web stack, module by module, in the order the concepts are typically introduced. Each module is self-contained and includes source files, practice problems, or a runnable mini-project.

**Scope covered:**

- Semantic HTML5 & CSS3 fundamentals
- Version control with Git & GitHub
- Core JavaScript (variables, conditionals, loops, functions, strings, objects, arrays, the DOM)
- Modern JavaScript with ES6+ syntax and problem solving
- TypeScript fundamentals, advanced typing, and OOP
- React (with TypeScript + Vite) through applied mini-projects

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mith9n/AI-Driven-Full-Stack-Web-Engineering.git
cd AI-Driven-Full-Stack-Web-Engineering
```

**Run a static HTML/CSS/JS module:**

Simply open the `.html` file in a browser, or serve it with a lightweight local server (e.g. the VS Code "Live Server" extension).

**Run a TypeScript file:**

```bash
npx ts-node filename.ts
```

**Run a React + Vite project** (Modules 28, 29, 31):

```bash
cd "Module 28 - react-simple-project-GeoVerse-with-GPT"
npm install
npm run dev
```

## Roadmap

The repository name reflects the intended end-to-end scope of the course. Content so far covers the **front-end** track in depth; the following are natural next additions to complete the **full-stack** and **AI-driven** parts of the curriculum:

- Backend fundamentals with Node.js & Express
- REST API design and database integration (MongoDB / SQL)
- Authentication & authorization
- AI/LLM API integration patterns (building on the GPT-powered React project in Module 28)
- Deployment & CI/CD

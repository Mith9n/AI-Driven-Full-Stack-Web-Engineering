# FitLog

**Train with intent. Log every set.**

FitLog is a workout library and planning companion for discovering exercises, checking workout details, and keeping a personal plan close at hand. Its dark interface and bright lime accents put the focus on your next session.

## Features

- **Explore the workout library** — Browse exercises with muscle groups, equipment, duration, calorie estimates, and ratings.
- **View workout details** — Open an individual workout to see more information and decide whether it belongs in your routine.
- **Build your plan** — Add workouts to your personal plan and revisit them on the My Plan page.
- **Save workouts for later** — Keep favorites handy without adding them to your current plan.
- **Stay in sync across pages** — Plan and saved-workout counts update throughout the app as you make changes.

## Technologies

- [Next.js](https://nextjs.org/) 16 with the App Router
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) 4
- [Lucide React](https://lucide.dev/) icons
- [React Toastify](https://fkhadra.github.io/react-toastify/) notifications
- Browser local storage for saved workouts and plans
- FitLog workouts API for workout library data

## Getting started

You'll need Node.js and npm installed.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use FitLog.

To create a production build:

```bash
npm run build
npm run start
```
